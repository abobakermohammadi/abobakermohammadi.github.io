Agent systems · Open source

AEGIS

A mission system for coding agents that refuses to confuse impressive output with verified outcomes.

Thesis

Evidence or it didn’t happen.

AEGIS turns a coding agent workflow into explicit mission state, checkpoints, routing and release gates. Verification is derived from executed evidence rather than confident prose.

The system

  • Persistent mission state and one-command resume
  • Evidence gates and git-aware staleness
  • Capability probes for workers instead of simulated agents
  • Usage-aware task routing
  • Regression memory and deterministic benchmark missions

Why I built it

Autonomous coding gets interesting only when the agent can survive long projects without losing truth. AEGIS is the attempt to make planning, memory, verification and shipping part of the same loop.

Engineering shape

The core is intentionally lightweight: Python 3.9+ standard-library tooling, Markdown-based skills, deterministic helper scripts and a benchmark harness. The public repository includes the mission engine, usage optimizer, second-brain context tools, plain-language ownership skill and verification scripts.
