Native iPhone experiment · SwiftUI

NEWAPP

An intentionally narrow book-discovery experiment: free, account-free, ad-free, local-first, and built around Home, Library and Search.

Constraint as product strategy

Less surface area. More truth.

Instead of bolting on subscriptions, social features, tracking and commerce before the core experience is proven, v1 removes them entirely.

What exists

  • Native SwiftUI iPhone app
  • Home · Library · Search
  • Local Must Read / Read state
  • Deterministic provider/canonical package
  • Provider evidence and territory gates

Release posture

The repository is built to fail closed. Provider-dependent features stay absent until evidence exists, and release verification cannot pass without Xcode plus real device/provider evidence.

Why it matters

NEWAPP is as much an experiment in product discipline as book discovery: prove the smallest useful native experience, keep invisible complexity out, and make App Review risk something the architecture actively checks.
