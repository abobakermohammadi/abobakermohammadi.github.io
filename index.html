Rules I keep repeating.

Different products, same few instincts underneath.

Show the truth.

If inventory is empty, show empty. If a provider is not verified, fail closed. If checkout does not exist, do not draw one.

Guide the decision.

Whether it is an exam, a book or a mosquito screen, the product should reduce “what do I do now?” into the next obvious action.

Ship the boring parts.

Auth, recovery, release checks, admin workflows, accessibility and failure states are part of the product, not cleanup after the fun work.
